## 개요

브라우저에서 실행되는 스도쿠 게임. 사용자는 퍼즐의 빈 셀에 숫자를 입력하고, 행·열·3×3 박스 규칙을 기준으로 즉각적인 색상 피드백을 받으며 게임을 완성한다.

## 범위

### 포함
- 9×9 스도쿠 퍼즐 생성 및 진행
- 난이도 선택 (easy / normal / hard)
- 셀 선택 → 숫자 입력(키보드/화면 버튼) → 즉시 색상 피드백
- 숫자 지우기
- 힌트: 선택한 셀에 정답을 자동 입력
- 게임 클리어 판정 및 새 게임 시작
- 다크모드 토글

### 제외
- 타이머 / 점수 / 리더보드 — 요구사항에 없음
- 게임 저장 / 이어하기 — 요구사항에 없음
- 실행 취소(Undo) — 요구사항에 없음

## 시나리오

### 1. 게임 시작 — 난이도 선택

- **Given** — 페이지가 처음 로드된 상태
- **When** — "게임 시작" 버튼을 클릭한다
- **Then** — Easy / Normal / Hard 세 가지 난이도 선택 화면이 나타난다.

성공 기준:
- [ ] "게임 시작" 클릭 → Easy / Normal / Hard 선택지가 표시된다

### 2. 난이도 선택 후 퍼즐 시작

- **Given** — 난이도 선택 화면이 표시된 상태
- **When** — 난이도 중 하나를 선택한다
- **Then** — 완성된 스도쿠 정답 판에서 난이도에 따라 일부 숫자만 남긴 9×9 격자가 표시된다. 단서 셀은 시각적으로 구분된다.
  - Easy: 전체 81칸 중 약 50%(≈40칸)의 숫자가 단서로 표시된다
  - Normal: 약 40%(≈32칸)의 숫자가 단서로 표시된다
  - Hard: 약 30%(≈24칸)의 숫자가 단서로 표시된다

성공 기준:
- [ ] Easy 선택 → 단서 셀이 약 40개 표시된다
- [ ] Normal 선택 → 단서 셀이 약 32개 표시된다
- [ ] Hard 선택 → 단서 셀이 약 24개 표시된다
- [ ] 단서 셀은 일반 입력 셀과 시각적으로 구별된다

### 3. 셀 선택

- **Given** — 게임이 진행 중이고 빈 셀들이 있다
- **When** — 빈 셀을 클릭한다
- **Then** — 해당 셀이 선택된 상태로 강조 표시된다. 단서 셀은 선택되지 않는다.

성공 기준:
- [ ] 빈 셀 클릭 → 해당 셀이 선택 표시(하이라이트)된다
- [ ] 단서 셀 클릭 → 선택되지 않고 아무 변화 없다
- [ ] 이미 선택된 셀 외 다른 빈 셀 클릭 → 선택이 새 셀로 이동한다

### 4. 숫자 입력 — 규칙 통과 (파랑)

- **Given** — 빈 셀 또는 사용자가 입력한 숫자(파랑/빨강)가 있는 셀이 선택된 상태
- **When** — 키보드 1~9 키 또는 화면 하단 1~9 버튼으로 숫자를 입력한다. 해당 숫자가 같은 행, 같은 열, 같은 3×3 박스 어디에도 중복되지 않는다.
- **Then** — 셀에 입력한 숫자가 파란색으로 표시된다. 기존 숫자가 있었다면 새 숫자로 덮어쓰여진다.

성공 기준:
- [ ] 빈 셀에 중복 없는 숫자 입력 → 해당 셀에 파란색 숫자가 표시된다
- [ ] 화면 버튼 클릭으로 입력해도 동일하게 파란색으로 표시된다
- [ ] 파란색 숫자가 있는 셀에 중복 없는 다른 숫자 입력 → 새 숫자로 파란색 교체된다
- [ ] 빨간색 숫자가 있는 셀에 중복 없는 숫자 입력 → 새 숫자로 파란색 교체된다

### 5. 숫자 입력 — 규칙 위반 (빨강)

- **Given** — 빈 셀 또는 사용자가 입력한 숫자(파랑/빨강)가 있는 셀이 선택된 상태
- **When** — 입력한 숫자가 같은 행, 같은 열, 또는 같은 3×3 박스에 이미 존재한다
- **Then** — 셀에 입력한 숫자가 빨간색으로 표시된다. 기존 숫자가 있었다면 새 숫자로 덮어쓰여진다.

성공 기준:
- [ ] 같은 행에 중복된 숫자 입력 → 빨간색으로 표시된다
- [ ] 같은 열에 중복된 숫자 입력 → 빨간색으로 표시된다
- [ ] 같은 3×3 박스에 중복된 숫자 입력 → 빨간색으로 표시된다
- [ ] 파란색 숫자가 있는 셀에 중복된 숫자 입력 → 새 숫자로 빨간색 교체된다

### 6. 숫자 지우기

- **Given** — 사용자가 입력한 숫자(파랑 또는 빨강)가 있는 셀이 선택된 상태
- **When** — Backspace 또는 Delete 키를 누른다 (또는 화면의 지우기 버튼을 클릭한다)
- **Then** — 해당 셀이 다시 빈 셀로 돌아간다.

성공 기준:
- [ ] 파란색 숫자가 있는 셀에서 Backspace → 셀이 비워진다
- [ ] 빨간색 숫자가 있는 셀에서 Delete → 셀이 비워진다
- [ ] 단서 셀에서 지우기 시도 → 변화 없다

### 7. 힌트 사용

- **Given** — 빈 셀 또는 사용자가 입력한 오답(빨강) 셀이 선택된 상태
- **When** — "힌트" 버튼을 클릭한다
- **Then** — 선택한 셀에 정답 숫자가 자동으로 채워지고, 파란색으로 표시된다. 힌트로 채워진 셀은 이후 수정(숫자 입력·지우기)이 불가능하다.

성공 기준:
- [ ] 빈 셀 선택 후 힌트 클릭 → 해당 셀에 파란색 정답 숫자가 채워진다
- [ ] 빨간색 숫자가 있는 셀 선택 후 힌트 클릭 → 정답 숫자로 덮어쓰여지고 파란색이 된다
- [ ] 파란색 숫자가 있는 셀 선택 후 힌트 클릭 → 변화 없다
- [ ] 힌트로 채워진 셀 클릭 후 숫자 입력 시도 → 변화 없다
- [ ] 힌트로 채워진 셀 클릭 후 지우기 시도 → 변화 없다
- [ ] 셀이 선택되지 않은 상태에서 힌트 클릭 → 아무 일도 일어나지 않는다

### 8. 게임 클리어

- **Given** — 게임이 진행 중이다
- **When** — 마지막 빈 셀에 숫자를 입력하여 모든 셀이 채워지고, 빨간색(규칙 위반) 셀이 하나도 없다
- **Then** — "게임 클리어" 메시지가 표시되고, "새 게임" 버튼이 나타난다. 보드는 잠금 상태가 되어 셀 선택·숫자 입력·지우기·힌트가 모두 불가능하다.

성공 기준:
- [ ] 모든 셀 채움 + 규칙 위반 없음 → "게임 클리어" 메시지가 표시된다
- [ ] "게임 클리어" 상태에서 "새 게임" 버튼이 보인다
- [ ] 빨간색 셀이 남아 있는 상태에서 나머지 셀을 모두 채워도 → 클리어 메시지가 표시되지 않는다
- [ ] 클리어 후 셀 클릭 → 선택되지 않는다
- [ ] 클리어 후 숫자 키 입력 → 보드에 변화 없다

### 9. 새 게임 시작

- **Given** — "게임 클리어" 메시지와 "새 게임" 버튼이 표시된 상태
- **When** — "새 게임" 버튼을 클릭한다
- **Then** — 난이도 선택 화면이 다시 표시된다 (시나리오 1과 동일한 흐름).

성공 기준:
- [ ] "새 게임" 클릭 → Easy / Normal / Hard 선택 화면이 표시된다
- [ ] 난이도 선택 후 → 이전 게임의 입력이 없는 새 퍼즐이 표시된다
- [ ] "게임 클리어" 메시지가 사라진다

### 10. 다크모드 토글

- **Given** — 게임 화면이 표시된 상태 (라이트 또는 다크 모드)
- **When** — 다크모드 토글 버튼을 클릭한다
- **Then** — 전체 화면의 색상 테마가 반전된다. 재클릭 시 원래 테마로 돌아간다.

성공 기준:
- [ ] 라이트 모드에서 토글 클릭 → 배경이 어두운 색으로 전환된다
- [ ] 다크 모드에서 토글 클릭 → 배경이 밝은 색으로 전환된다

## 불변 규칙

**규칙 일관성** — 파랑/빨강 색상 판정은 항상 현재 보드 상태를 기준으로 즉시 반영된다. 어떤 셀의 숫자를 지우거나 변경하면, 그 셀과 같은 행·열·박스를 공유하는 다른 셀들의 색상도 즉시 재계산된다.
